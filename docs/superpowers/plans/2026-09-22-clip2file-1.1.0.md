# Clip2File 1.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with verification checkpoints.

**Goal:** Add English/Simplified Chinese localization and a right-click format submenu while preserving the existing smart-save behavior.

**Architecture:** Use Chrome native `_locales` resources for manifest and browser-selected locale behavior, with a small runtime `t()` adapter for popup/options/background dynamic text. Introduce a tested core format-policy layer and route context-menu actions through explicit `SaveMode` values; keep content extraction, image fetching, and download boundaries in the service worker.

**Tech Stack:** TypeScript, Chrome Manifest V3, Vite, Vitest, JSZip, Chrome `i18n` and `contextMenus` APIs.

**Spec:** `docs/superpowers/specs/2026-09-22-i18n-context-format-design.md`

## Global Constraints

- Target version is `1.1.0`.
- Supported locales are `en` and `zh_CN`; unsupported browser locales fall back to English.
- The existing smart-save path remains available and keeps its current behavior.
- Explicit format selection never silently downgrades and is not persisted.
- Multi-file projects cannot be forced into TXT, Markdown, or HTML.
- Image-only content cannot be saved as plain text.
- All processing remains local; do not add remote services or telemetry.
- Replace privacy-policy contact placeholders with `bk4ice@gmail.com`.
- Do not include the existing untracked product-plan markdown file in changes.
- Before code edits, fetch the remote repository and stop if the remote contains commits missing locally.
- After verification and passing tests, create a commit and push it to `origin/main`.

### Task 4: Extract and test explicit format policy

**Files:**
- Create: `src/core/save-format.ts`
- Create: `tests/save-format.test.ts`
- Modify: `src/core/types.ts` only if existing types need a minimal shared representation

**Interfaces:**
- Produces:

```ts
export type SaveMode = 'auto' | 'text' | 'markdown' | 'html' | 'zip';

export interface FormatContext {
  hasText: boolean;
  imageCount: number;
  isProject: boolean;
  suggestedFilename: string;
}

export interface FormatDecision {
  allowed: boolean;
  reason?: 'empty' | 'text-required' | 'project-requires-zip' | 'text-cannot-save-images';
  extension: string;
  filename: string;
}

export function decideFormat(mode: SaveMode, context: FormatContext): FormatDecision;
```

- [ ] **Step 1: Write failing policy tests.**

Cover these exact cases:

```ts
expect(decideFormat('auto', { hasText: true, imageCount: 0, isProject: false, suggestedFilename: 'main.py' }).extension).toBe('.py');
expect(decideFormat('text', { hasText: true, imageCount: 0, isProject: false, suggestedFilename: 'main.py' }).extension).toBe('.txt');
expect(decideFormat('markdown', { hasText: true, imageCount: 1, isProject: false, suggestedFilename: 'note.txt' }).extension).toBe('.md');
expect(decideFormat('html', { hasText: false, imageCount: 1, isProject: false, suggestedFilename: 'image.png' }).extension).toBe('.html');
expect(decideFormat('text', { hasText: false, imageCount: 1, isProject: false, suggestedFilename: 'image.png' }).allowed).toBe(false);
expect(decideFormat('markdown', { hasText: true, imageCount: 0, isProject: true, suggestedFilename: 'project.zip' }).allowed).toBe(false);
expect(decideFormat('zip', { hasText: true, imageCount: 0, isProject: true, suggestedFilename: 'project.zip' }).allowed).toBe(true);
```

- [ ] **Step 2: Run focused tests and verify failure.**

Run:

```bash

```

Expected: FAIL because the policy module is not implemented.

- [ ] **Step 3: Implement the minimal decision policy.**

Preserve the detected extension for `auto`, force `.txt`/`.md`/`.html`/`.zip` for explicit modes, sanitize the basename with the existing sanitizer, and return a structured rejection rather than silently selecting another mode.
